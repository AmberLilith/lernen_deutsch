Preposições

Verbos com preposição fixa

Präpositionalverben — verbos que sempre vêm acompanhados de uma preposição específica, com sentido próprio (parecido com "phrasal verbs" do inglês).

O que são

Alguns verbos "casam" com uma preposição fixa, formando um sentido que não dá pra adivinhar só pela soma das partes.

warten auf · esperar por → Ich warte auf den Zug. (Eu espero pelo trem.)

sich freuen auf · ficar animado com algo futuro → Sie freut sich auf die Reise.

sich freuen über · ficar feliz com algo já acontecido → Er freut sich über das Geschenk. (Geschenk = presente, novo)

denken an · pensar em → Ich denke an dich.

sich interessieren für · se interessar por → Wir interessieren uns für Musik.

Angst haben vor · ter medo de → Sie hat Angst vor Hunden.

Particularidade importante

A preposição usada aqui não segue a lógica normal de Wechselpräposition (movimento x localização) — o caso é fixo pelo verbo, não pela situação.

warten auf + Akkusativ · sempre, mesmo sem "movimento"

Angst haben vor + Dativ · sempre

Ou seja, aqui não dá pra usar a pergunta "onde/para onde" — tem que decorar caso a caso, junto com o verbo.

A preposição permanece fixa

A preposição fixa não muda em nada — ela é fixa mesmo, independente do tempo verbal. Só o verbo se conjuga normalmente na estrutura de cada tempo.

Präteritum

Ich wartete auf den Arzt. (Eu esperava/esperei pelo médico.)

Sie freute sich über das Geschenk.

Perfekt

Ich habe auf den Arzt gewartet.

Sie hat sich über das Geschenk gefreut.

Repara: no Perfekt, a preposição fica "presa" perto do verbo (auf ... gewartet), não some nem se separa. O particípio vai para o final, enquanto a preposição + objeto permanecem na posição normal deles.

Futur I

Ich werde auf den Arzt warten.

Mesma lógica dos modais: werden na posição 2, e auf den Arzt warten (preposição + objeto + infinitivo) fica no final.

Em oração subordinada

Ich denke, dass ich auf den Arzt gewartet habe.

A preposição + objeto ficam no meio, e só o(s) verbo(s) vai(vão) para o final, seguindo a regra normal de subordinada.

da + preposição (da-Kompositum)

Quando o objeto de uma preposição fixa é uma coisa/ideia (não uma pessoa), você não usa "preposição + das/es" — usa da(r) + preposição, grudado numa palavra só.

Ich freue mich darüber. (Eu me alegro com isso.) — não "über das"

Ich warte darauf. (Eu espero por isso.) — não "auf das"

Ich interessiere mich dafür. (Eu me interesso por isso.) — não "für das"

Regra de formação

Regra: da- + preposição.

Se a preposição começa com vogal (an, auf, über...), entra um -r- no meio para facilitar a pronúncia:

darauf · darüber · daran

Se começa com consoante (für, mit, von...), fica somente da-:

dafür · damit · davon

Quando NÃO usar da-

Se o objeto é uma pessoa, usa-se a preposição normal + pronome pessoal, sem da-.

Ich denke an ihn. (Eu penso nele.)

Não usamos daran nesse caso, porque daran significa "nisso", ou seja, retoma uma coisa, ideia ou situação.

Ich warte auf sie. (Eu espero por ela.)

Perguntas com wo(r)-

A mesma lógica de da(r)- funciona nas perguntas sobre coisas, ideias ou situações.

Worauf wartest du? (Pelo que você espera?)

Woran denkst du? (Em que você pensa?)

Para pessoas, usamos a preposição normal + pronome interrogativo:

Auf wen wartest du? (Por quem você espera?)

An wen denkst du? (Em quem você pensa?)

Resumo

Aprenda cada verbo preposicional como uma unidade:

VERBO + PREPOSIÇÃO + CASO + SIGNIFICADO

Exemplos:

  • warten auf + Akk. → esperar por
  • denken an + Akk. → pensar em
  • sich interessieren für + Akk. → interessar-se por
  • Angst haben vor + Dat. → ter medo de

A preposição permanece fixa. O que muda conforme a frase é a conjugação do verbo e a estrutura temporal.
